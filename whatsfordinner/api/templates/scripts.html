{{/* Shared vanilla-JS behaviour for pages with a live "type to filter" search box (currently pantry.html and recipes.html). Kept in one place so both pages get identical behaviour without duplicating a script tag. Include once, right before the closing body tag, via {{template "search-script" .}}. Wire-up is entirely via data attributes, no page-specific JS needed: - the search input carries data-search-input pointing (as a CSS selector) at the container holding the results, and data-search-empty pointing at a hidden "no matches" element; - every filterable row inside that container carries data-search-name with the text to match against; - every card/section that should hide once all of its rows are filtered out carries a data-search-card attribute. Degrades gracefully with JS disabled: everything just stays visible, as if nothing had been typed. */}} {{define "search-script"}} {{end}}
